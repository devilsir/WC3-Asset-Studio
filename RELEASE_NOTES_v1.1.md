# WC3 Asset Studio v1.1

WC3 Asset Studio is a visual asset workspace for Warcraft III modding, combining texture painting, model previewing, UV inspection, Warcraft III button creation, sanity checking and optional CASC-assisted asset loading.

Version 1.1 improves Texture Paint navigation and alpha editing, adds move/rotate workflows, expands button-frame customization, improves UV handling and CASC/model effect playback, and automatically searches for textures referenced by imported MDX/MDL models.

The Windows build is available as a portable application and does not include Warcraft III game files.

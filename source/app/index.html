Effects Lab — what each control does
Quick reference for Designer, Live Preview and the CFX/PKB workflow.
?
Project
Effect name — name used by the generated trigger/script.
Refresh cycle — timer tick in seconds. Lower values update more often.
Probability — chance that the effect is created when the trigger fires.
Trigger — event that starts the effect: cast, attack, damage, death, item use, etc.
Target — whether the effect is tied to a point, units or an immediate action.
Ability ID — rawcode used to filter spell-related triggers.
Hashtable — variable name used by generated Lua/JASS state storage.
Layer
Layer name — readable name for one timing group.
Layer type — independent layers run alone; related layers can follow another layer.
Reference — origin used by the layer: default, target, caster or previous layer.
Start — delay before this layer begins.
Duration — how long the layer remains active.
Interval — repeat/update interval for this layer.
Related layer — layer identifier used when Layer type is Related.
Object
Type — kind of object created by the layer: effect model, dummy unit, sound, lightning, text, etc.
Scale — visual size multiplier.
Model / resource path — virtual Warcraft path to the model/sound/resource. Browse CASC searches assets already present in Warcraft storage; nothing is extracted or modified.
Life span — time before the object is removed.
Animation — model animation requested for model-based objects, usually stand.
Preview & editing
Examples / Learn — complete examples that populate Designer, CFX/PKB, Graph, Samplers, Renderers and Code. Load opens the finished preset; Learn asks for speed + accent color and guides each click with an animated RGB border.
Live Effect — approximate real-time CFX renderer preview using CASC/CDN or external local textures, atlas, blend, lifetime and particle motion. The toolbar above the viewer can add, duplicate or delete renderers and edit Type, Blend, Texture, Atlas, Enabled and Draw order directly in renderers.cfx. Use CASC for Warcraft textures or Local for BLP/DDS/TGA/PNG/JPG/WEBP/BMP files outside the game storage.
Motion Debug — drives the rendered effect through the selected motion trajectory and init shape while keeping the guide visible. Built-in presets can be replaced by mathematical parametric functions. Example: set the domain to -1 → 2 and use Z = x^2 + 2. Variables include x/t/i, radius, height, turns, parameters a/b/c/d, and constants pi/e/tau.
Reload textures — re-read every renderer texture from its source, whether Warcraft CASC/CDN or an external local file.
Reset view — restores preview camera/orbit.
Generated trigger starter — Lua/JASS helper generated from the EPF project. It is collapsed by default so the preview gets more space.
Import / Export — Effects Lab keeps a native internal project model. CFX is an import/export adapter; PKB decompile/build is handled by a user-selected external backend. Unverified third-party binaries are not bundled.
Code editor — IDE-style syntax colors plus live validation. Functions, strings, numbers, references and keywords are highlighted; invalid lines turn red and Apply/Build is blocked while hard errors remain.
Graph / Layers — visualizes spawn/event connections. Samplers edits curves/shapes. Renderers edits billboard/ribbon/light/mesh blocks. Code edits the raw bundle files.

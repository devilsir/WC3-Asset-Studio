Standalone MDX/MDL files now search their local model folder for referenced textures using the same resolver as Model Lab; a custom texture becomes Severe only after that automatic lookup actually fails. ZIP/package checks still validate package contents directly. Animation boundary keys and rig/binding repairs remain optional. Every FIX/SKIP is logged with before/after values and proof details.
